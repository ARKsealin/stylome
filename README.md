# Stylome - 科幻写作辅助组件

基于文学计算相关理论，结合参数辨识、特征分析与迁移学习等技术，面向中文科幻写作开发的辅助工具集。该组件旨在让作者看见自己文本的风格与结构，并把这些观察变成可操作的写作参考。

全部计算在本地完成，以 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）插件形态安装运行。三个插件共享同一套测量层，所有结论均基于可量化与可解释的指标进行分析。

本组件共三个DSH插件，无交叉依赖关系，可根据具体需求自行选择安装。

| 插件 | 关注问题 | 核心能力 |
|---|---|---|
| [stylome-identify](plugins/stylome-identify/) | 写作特征 | 基于预训练权重与迁移学习判别给定作品AIGC概率 |
| [stylome-weaver](plugins/stylome-weaver/) | 文风习惯 | 根据多种文学计量特征参数分析行文习惯，并结合锚定作者风格给出参考意见 |
| [stylome-architect](plugins/stylome-architect/) | 叙事结构 | 基于叙事动力学与场景划分分析并归档作品的叙事结构，并以场景为最小颗粒度提供自定义修改参考 |

## StylomeIdentify - 以铜为鉴，可以正衣冠

StylomeIdentify 面向中文科幻文本的 AI 参与判别问题，采用计量特征与迁移学习相结合的混合判别架构。其判别栈分为三层：L0 完成文本清洗与微段路由；L1 在逐窗测量层提取句法节奏、词汇分布、段落形态、重复结构等文学计量特征，并借助冻结的多语言句向量编码器获得语义层面的迁移特征；判别层以线性判别模型为主判别器，融合经方向一致性检验准入的辅助判别器，并以 conformal 方法给出与误判代价挂钩的置信分层。全部判定线由参照分布的分位数派生，政策参数（可接受错误率）与每条判定线的派生方式均随模型文件记录，判别过程整体可审计、可复现。

- **四态判决**：高度疑似 / 存在嫌疑 / 混合可能 / 人工创作，附带 conformal 置信分层（高 / 中 / 低 / 弃权 / 证据冲突 / 样本不足）
- **逐特征证据表**：每个特征给出取值、方向与贡献排序，结论可逐项追问
- **长文本诊断**：逐窗光谱与变点定位，标示可疑区间在全文中的位置
- **判别档案**：每次判别完整存档，可按文件路径或档案号原样回放；同一篇文本的跨版本判别构成可追溯的历史序列

## StylomeWeaver - 以古为鉴，可以知兴替

StylomeWeaver 将作者的文风习惯表征为一组可度量的统计分布。插件从用户提供的样本集中提取段落长度节奏、句长分布、词汇复杂度、功能词与词性配比、对白与标点习惯等多维文学计量特征，为每一项特征学习参照分位带，并以带外预算 α 作为合规判据——判定线由数据自身派生，随样本规模与分布自动校准。在此之上，各特征按固定展示刻度映射为九轴风格指纹，与逐段偏离档位共同构成作者文风的显式参照系。

- **画像训练**：`/weaver train` 从样本文件夹批量学习作者画像，画像存于用户级目录并随训练持续更新
- **逐段校验**：`/weaver compare` 对待检文本逐段计算偏离量，划分为越带 / 关注 / 轻微偏离 / 在带内四档
- **带外定位与修改意见**：带外发现落到原文片段，并区分对齐画像的调整与有意突破画像的尝试
- **面板可视化**：九轴雷达、逐段热力与画像卡片

## StylomeArchitect - 以人为鉴，可以明得失

StylomeArchitect 以整篇作品为单位考察宏观叙事织体，方法基础来自计算叙事学。插件以变点自适应算法将文本切分为叙事场景，以情感词汇本体为词典资源构建七类情绪弧线与 valence 双向弧线，并结合节奏与长程相关性的时序统计刻画情绪节奏的形态；每个场景进一步映射到标准化的叙事功能向量空间，标注其在上下文之间的结构作用。多作者档案库按作者分区归档作品信号，在锚定标注之上支持跨作者信号检索，使修改建议得以在迁移层面参照他作。

- **作品档案**：情感弧线、valence 弧、节奏与分形指标、对白-叙述交替、关键词回响
- **输出 A（自我参照）**：以锚定作者档案库为基线，报告作品相对自身历史的忠实度与变化
- **输出 B（跨作者迁移）**：按信号相似度检索库内其他作者的作品，指出相似所在并给出可参考的改写方向
- **场景引擎**：逐场景功能标注与叙事动力学标签；场景可单独选中比对，亦可按功能向量检索库内同类场景
- **L2 语义契约**：伏笔-回收、情绪归因、实体轨迹等标注任务交由 agent 完成，结果回填档案库形成标注飞轮

## 安装

| 依赖 | 要求 |
|---|---|
| Node | ≥ 22.13 |
| DSH | ≥ 0.2.1-rc.3 |
| Python | 3.8+，安装 jieba |

```text
plugin_manager(action: "install_bundle", target: "<本仓库路径>/plugins/<插件目录>")
```

三个插件出厂均为待初始化状态：identify 开箱即用（首次判别自动下载句向量模型）；weaver 的第一次 `train` 建立你的画像；architect 先收录作品、再标注锚定作者。各插件 README 内有具体步骤，`node verify.mjs` 做本地自检。
