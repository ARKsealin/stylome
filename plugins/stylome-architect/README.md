# stylome-architect

宏观织体校验器。以整篇作品为单位考察叙述结构、情感节奏与场景功能，输出自我参照（输出 A）与跨作者迁移（输出 B）两路结果；场景引擎以场景为最小颗粒度支持逐场景比对与功能检索。全部分析基于本地统计测量与档案库归档。

## 原理：三重观测尺度

**作品级。** 情感轨以大连理工大学《情感词汇本体库》为词典资源，逐段累计七类情绪强度与 valence 双向值，按汉字位置十分位聚合为情感弧线。节奏侧以三项时序统计刻画情绪节奏的形态：R（情绪显影总量）度量情绪词强度的累计水平，Q（情绪逐档变化总量）度量相邻十分位间的情绪波动，H（句长赫斯特维数，DFA 估计）与分段局部赫斯特刻画句流节奏的长程相关结构。此外记录叙述-对白交替率与对白曲线、关键词回响（意象与母题的复现）、首尾呼应与 gap-return 等线索信号。

**场景级。** 变点自适应切分将段落流划分为叙事场景；每个场景计算七维功能向量（位置、情绪水平、情绪斜率、入跳变、出跳变、对白强度、张力）并映射功能标签。叙事动力学标签采用 Todorov 均衡逻辑与 Sternberg 叙事动力的词表：EQ 均衡（日常态）/ DIST 失衡（事件打破）/ STRUGGLE 对抗与探究 / NEWEQ 新均衡（收束），辅以 SUS 悬念（知今未知果）/ CUR 好奇（知果未知因）/ SUR 惊奇（突揭）三类动力强度。

**实体级（L2）。** 实体时间线、伏笔-回收、情绪归因等需要语义理解的标注任务交由 agent 完成（L2 语义契约），标注结果经 `annotate` 回填档案库，构成「浅统计 → agent 标注 → 更强画像」的标注飞轮。

## 档案库

档案库按作者分区归档作品，每部作品一份档案（dossier）：作品级信号、逐场景特征与功能标注、实体轨迹及回填标注。用户指定其中一个作者分区为锚定风格；其余分区作为迁移参考的语料来源。档案库存于用户级目录 `~/.stylome-architect/library/`，出厂为空。

## 双输出

**输出 A（自我忠实与进步变化）。** 以锚定作者全部档案为参照分布，对作品的每项核心指标给出三档判读：忠实核心（|z| ≤ 1）、自我边缘、超出自身历史；边缘与超出项汇总为「进步变化」清单——它们构成风格演进的候选信号，与带外发现的原文片段一同呈现。

**输出 B（跨作者迁移）。** 按六个侧面在库内检索信号最相近的他作：情绪显影浓度、情感弧形状、句流节奏、对白织体、线索手法、场景手艺。每个侧面给出「像哪篇、哪方面像、可参考什么」，并回放两侧的对应信号值供直接对照；迁移池样本不足时给出明确说明。

## 场景引擎

- **功能检索**：以七维功能向量在库内跨作品检索同类功能的场景，回答「这一场景的功能节奏可以参照谁」
- **场景级比对**：任意场景与锚定档案逐项对照，给出最显著的差异维度
- **神经轨（可选）**：逐场景句向量聚合为轨迹，支持轨迹级近邻检索与新颖度报告；属显式 opt-in 功能，模型缺席时纯统计链路照常工作

## 使用

```text
工具 stylome_architect（mode）：
  weave    织体校验：双输出 + 场景轨 + 修改建议 + L2 任务清单
  ingest   收录作品：<作者> <文件/目录>
  mark     标注锚定风格（唯一）
  list     查看档案库
  annotate 标注回填：将 agent 标注写入档案

命令 /architect 提供常用操作；侧栏「StylomeArchitect」面板提供档案库管理、
场景轨与条纹图、实体轨迹的可视化。
```

典型流程：`ingest` 收录锚定作者作品 → `mark` 标注锚定 → `weave` 校验待检文本 →（可选）收录其他作者作品以启用迁移参考，`annotate` 回填 L2 标注。

## 外部资源

- **情感词典**：体检发现缺失时，面板弹窗请用户确认，确认后插件从官方页下载附件并转存至用户目录（官方条款与引用要求见仓库根 [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)）；手动放置同样可行
- **句向量模型**（可选）：开启神经轨时自动下载至 `~/.stylome/models/`，用法同仓库根说明

## 安装与自检

```text
plugin_manager(action: "install_bundle", target: "<本仓库>/plugins/stylome-architect")
```

Python 环境要求 3.8+，安装 `jieba`；可选依赖见 [requirements.txt](./requirements.txt)。`stylome_architect_doctor` 或 `node verify.mjs --doctor` 检查 node / Python / jieba 桥 / 词典 / 测量核 / 档案库；`node verify.mjs` 跑本地自检。
