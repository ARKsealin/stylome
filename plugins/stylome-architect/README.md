# stylome-architect

宏观织体校验器。weaver 看句子与段落，architect 看整篇与场景：叙述结构是否立得住，情感节奏怎么呼吸，线索与伏笔在哪里埋、又在哪里收。

## 它做什么

- **作品档案**：情感七类弧线、valence 弧、节奏与分形维度（R/Q/H）、对白-叙述交替、关键词回响——整篇一份档案
- **多作者档案库**：按作者分区收录作品，其中一组标注为锚定风格，档案库随之给出「自我忠实与进步变化」（输出 A）
- **迁移参考**：按信号相似度在库内检索其他作者的作品，指出像哪篇、哪方面像、可以参考什么（输出 B）
- **场景引擎**：变点自适应切分场景，逐场景标注功能向量与叙事动力学标签；场景可单独选中比对，也能按功能在库内检索同类场景
- **L2 语义契约**：场景切分确认、伏笔-回收、情绪归因、实体轨迹等标注任务交给 agent 完成，结果回填档案（标注飞轮）

## 快速开始

```text
① 收录作品：工具 stylome_architect，mode=ingest <作者> <文件/目录>
② 标注锚定：mode=mark <作者>
③ 织体校验：mode=weave <文件>
```

档案库在用户级 `~/.stylome-architect/library/`，出厂为空。命令 `/architect` 提供常用操作，侧栏「StylomeArchitect」面板提供档案库管理、场景轨与条纹图的可视化。

## 外部资源

- **情感词典**：大工《情感词汇本体库》。体检发现缺失时，面板会请你确认，确认后插件从官方页代为下载官方附件并转存到用户目录；手动放置同样可行。条款与引用要求见仓库根 [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)
- **句向量模型**（可选）：开启神经轨（逐场景语义比对）时自动下载，关闭时纯统计三轨照常工作
