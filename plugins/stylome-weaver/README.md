# stylome-weaver

作者风格锚定与比对器。以用户提供的参考样本训练作者文风画像，此后任何文本均可逐段对照画像，将偏离定位到原文片段，并给出方向性的修改意见。画像使「文风」从一种直觉转变为一组可度量的统计分布。

## 原理：文风的计量表征与分位带

**特征平表。** 以 jieba 分词桥为底座，对每个可校验段落提取多组文学计量特征：词汇丰富度（MATTR）、修饰性占比、功能词频、标点节奏、句长分布、人称代词分布（叙述部分）、对白占比、情绪词密度、框架句式（关联词对举），以及词性搭配与词面复现的分布统计，汇成扁平特征表。

**分位带画像。** 画像学习按「特征 × 段长档」进行：样本段落按长度分档，各档内为每项特征学习参照分位带；稀疏档自动合并以保障覆盖率。判定线由样本分布直接派生，带外预算 α 以可接受越带率为口径——画像的判定标准随样本规模与分布自动校准，并随训练持续更新。

**九轴风格指纹。** 九个展示轴——词汇多样性（lexdiv）、修饰词占比（lexmix）、功能词密度（fw）、标点密度（punct）、句长节奏（rhythm）、人称习惯（pron）、对白占比（dialog）、情绪密度（emo）、框架句式（frame）——按固定展示刻度映射至 0–1，构成雷达视图与画像卡片。展示刻度仅用于呈现；判定只发生在分位带上。

**逐段校验。** 待检文本逐段计算偏离量，归入四档：在带内 / 轻微偏离 / 关注 / 越带。带外发现落到原文片段；修改意见区分两种意图——对齐画像的调整与有意突破画像的尝试，后者由作者自行确认。

## 使用

```text
/weaver train <样本文件夹> [作者名]      建立 / 更新画像（文件夹内 .txt / .md 批量训练）
/weaver compare <画像id> <文件路径>      逐段校验 + 修改意见
/weaver profiles                         查看已有画像
/weaver doctor                           运行条件体检
```

画像存于用户级目录 `~/.stylome-weaver/profiles/`，支持多画像并行（不同作者或不同文体），目录记录作者、样本规模、带外预算与各档样本量。工具入口：`stylome_weaver_train` / `stylome_weaver_compare` / `stylome_weaver_profiles` / `stylome_weaver_doctor`。样本越丰富、覆盖越广，画像越稳。

## 面板

侧栏「StylomeWeaver」面板提供九轴雷达、逐段热力与画像卡片的可视化，校验结果与修改意见在面板与报告中同步呈现。

## 安装与自检

```text
plugin_manager(action: "install_bundle", target: "<本仓库>/plugins/stylome-weaver")
```

Python 环境要求 3.8+，安装 `jieba`；其余可选依赖见 [requirements.txt](./requirements.txt)。`/weaver doctor` 检查运行条件；`node verify.mjs` 用一段内置文本走完「测量 → 学画像 → 九轴指纹 → 逐段校验」全链路。出厂携带空白画像库，第一次 `train` 即建立用户自己的锚定画像。
